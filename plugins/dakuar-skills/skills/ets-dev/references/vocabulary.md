# Vocabulario

Estas listas aplican las reglas 6, 7, 8 y 9 de `SKILL.md`.

Si el proyecto ya usa otro término de forma constante, conserva el término del proyecto.

## Un término por concepto

Usa el término de la primera columna. No lo alternes con los términos de la segunda columna.

| Usa | No alternes con |
| --- | --- |
| archivo | fichero, documento (para un archivo de código) |
| carpeta | directorio |
| ejecutar | correr, lanzar, arrancar |
| eliminar | borrar, remover, quitar |
| crear | generar (para un archivo que una persona escribe) |
| agregar | añadir, incluir |
| configurar | setear, ajustar |
| error | fallo, problema, incidencia |
| prueba | test, testeo |
| función | método (si el código no usa clases), rutina |
| parámetro | argumento (elige uno por documento) |
| usuario | cliente (si "cliente" también nombra un programa) |

## Términos que no se traducen

Escribe estos términos en inglés. Los comandos y los nombres de rama van en formato de código.

- Operaciones de git: commit, push, pull request, merge, rebase.
- Nombres de herramientas y de productos.
- Nombres de archivos, de funciones, de variables y de rutas.

## Verbos en lugar de nominalizaciones

| No escribas | Escribe |
| --- | --- |
| realizar la instalación de | instalar |
| llevar a cabo la validación de | validar |
| hacer la comprobación de | comprobar |
| efectuar una llamada a | llamar a |
| proceder a la eliminación de | eliminar |
| dar inicio a | iniciar |
| hacer uso de | usar |
| tener la capacidad de | poder |

## Suavizadores

Elimina estas expresiones. Si la duda es real, escribe la duda como dato.

- quizás, tal vez, posiblemente, probablemente
- en principio, en teoría, en general
- debería, podría (cuando el texto describe un comportamiento conocido)
- creo que, parece que, diría que
- más o menos, aproximadamente (sin una cifra)
- un poco, bastante, algo

## Relleno

Elimina estas expresiones. La oración conserva su significado sin ellas.

- cabe destacar que, es importante mencionar que, vale la pena señalar que
- como se mencionó anteriormente, como ya sabes
- básicamente, simplemente, realmente, obviamente
- a continuación se muestra, en esta sección veremos
- con el fin de (usa "para")
- en el caso de que (usa "si")
- a la hora de (usa "al" o "cuando")
- debido al hecho de que (usa "porque")

## Adjetivos de calidad

Estos adjetivos no dan información sin un dato. Sustituye cada uno por una cifra o por una descripción del comportamiento.

- rápido, lento, ligero, pesado
- robusto, sólido, estable, fiable
- simple, sencillo, fácil, intuitivo
- limpio, elegante, moderno, potente
- mejor, peor, óptimo, eficiente
- seguro (sin nombrar la amenaza que cubre)
- escalable (sin nombrar la carga que soporta)
