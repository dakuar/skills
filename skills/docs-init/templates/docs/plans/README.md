# Plans

One file per plan: `NNN-short-name.md`. A plan is self-contained: an agent can execute it without the conversation that produced it.

## Status

| # | Plan | Status | Depends on |
| --- | --- | --- | --- |
| 001 | [<title>](001-<short-name>.md) | TODO | — |

Status values: `TODO`, `IN PROGRESS`, `DONE`, `REJECTED`. When a plan is `DONE`, add the change to `logs.md`.
